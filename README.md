# localXhost 🚀

A collection of lightweight, blazing-fast, single-file HTML utilities designed to run entirely inside your browser. No backend servers, no heavy frameworks—just pure, self-contained code that works offline.

## 🛠️ Featured Tools

| Tool Name | Description | Live Demo |
| :--- | :--- | :--- |
| **Background Remover** | Client-side image background removal running entirely in HTML5 Canvas. | [Try Live Demo](https://gitmfhub.github.io/localXhost/tool/bgremove) |

## ✨ Features

* **Offline-First (PWA):** Install tools directly to your device and use them without an internet connection.
* **Single-File Architecture:** Clean, readable, and portable code structures built with pure HTML, CSS, and JavaScript.
* **Privacy Focused:** All processing happens locally on your device; no data is ever uploaded to external servers.
